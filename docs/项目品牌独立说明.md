# 项目品牌独立说明

项目对外名称统一为“闲鱼拼多多助手”。Web 管理端、浏览器标题、通知文案、采集扩展、
桌面托盘和文档不再展示 Ydisks 推广内容，也不再跳转到 Ydisks 网站。

## 兼容策略

本阶段只修改用户可见品牌，不迁移已有安装的内部标识。以下名称暂时保留：

- Windows 服务名和数据目录 `YdisksXianyuHelper`
- macOS LaunchAgent 标识 `com.ydisks.xianyu-helper.*`
- Linux 服务、用户及数据目录 `ydisks-xianyu-helper`
- Compose 项目名、旧镜像名以及前端本地存储键

保留这些标识可确保升级后继续读取原数据库、配置、日志和浏览器资料。后续如需彻底改名，
应单独提供可回滚的迁移工具，而不是在常规升级中直接切换路径。

## 与商品数据的边界

“项目品牌独立”不新增或修改拼多多商品的品牌字段，也不会改动已采集商品、素材、SKU
映射或闲鱼平台商品。商品属性中的品牌仍按现有采集过滤规则处理。
